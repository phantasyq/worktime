# Быстрый старт

1. Создай OAuth Client ID типа **Web application** в Google Cloud.
2. Добавь origin GitHub Pages: `https://USERNAME.github.io`.
3. В `config.js` вставь Client ID.
4. Залей папку в GitHub.
5. Включи GitHub Pages для ветки `main` и корня репозитория.
6. Открой сайт и нажми «Подключить Google».
7. Разреши доступ к Google Sheets и Drive.
8. Приложение автоматически создаст таблицу `Work Time Tracker — Data`.

Для нескольких устройств используй один и тот же Google-аккаунт. Таблица является общей онлайн-базой.
