# Work Time — v3.1.1

## Новое
- Производственный календарь РФ загружается автоматически из API; ручные поля для праздничных/рабочих дат удалены.
- Добавлены встроенные резервные производственные календари для РФ на 2024–2027 годы с официальными переносами, включая 2026 и 2027 годы. Кэш источника действует 12 часов.
- Google access token сохраняется в `sessionStorage` текущей вкладки до истечения срока действия, поэтому простая перезагрузка страницы больше не вызывает повторный OAuth-вход, если токен ещё действителен.
- При истечении токена приложение показывает понятное сообщение и кнопку повторного входа.
- Ошибки закрытия/блокировки OAuth popup показываются пользователю, а не оставляют приложение в бесконечной загрузке.

## Исправления дебага
- Исправлена ошибка OAuth: раньше callback и error callback пытались задаваться на возвращённом объекте TokenClient после инициализации. Теперь реальные callback передаются в `initTokenClient`, как требует Google Identity Services.
- Убрана неработающая попытка получить токен через popup-less `prompt:none` при загрузке страницы; GIS требует user gesture для запроса access token. После reload используется действующий токен из текущей вкладки.
- Листы Sheets больше не очищаются отдельным запросом перед перезаписью. Замена выполняется одним атомарным `spreadsheets.batchUpdate` (очистка значений + запись новых), чтобы исключить потерю данных между двумя сетевыми вызовами.
- Settings и appData config больше не перезаписываются без необходимости при каждом обновлении данных; проверяется схема миграции.
- Пустой лист `TaskTemplates` остаётся пустым, если пользователь намеренно удалил все шаблоны; он также больше не перезаписывается на каждой загрузке. Стартовые шаблоны не появляются заново.
- Backup-list загружается только при открытой вкладке настроек, а не при каждой перерисовке календаря.
- Service Worker cache bumped to `work-time-shell-v7`.

## Производственный календарь
- Приоритет: онлайн-данные -> локальный кэш -> встроенный официальный календарь для годов 2024–2027 -> базовый предварительный календарь для ещё не опубликованных годов.
- Рабочие даты переноса (например, 2027-02-20) разрешены для списания, даже если приходятся на субботу.
- Праздники/переносы не нужно вводить вручную. Сокращённые дни остаются рабочими с нормой 8 часов, как требует внутренняя логика приложения.

## Ограничения, которые нужно знать
- Проверки в этом пакете — синтаксические, статические и unit-тесты. Живой OAuth и Google Sheets end-to-end требуют запуска опубликованного GitHub Pages с реальными настройками Cloud.
- Токен хранится только в `sessionStorage` текущей вкладки и действует ограниченное время. После истечения/отзыва доступ нужно восстановить кликом по Google button. Полностью автоматическое обновление сессии после закрытия вкладки требует backend; секреты и refresh tokens нельзя безопасно размещать в публичном GitHub Pages.
- Если календарь недоступен онлайн, используется встроенный/кэшированный fallback; производственные переносы на годы, для которых официальные решения ещё не опубликованы, могут быть только предварительными до обновления источника.


## v3.1.1 — проверка перед публикацией

- Повторный запуск больше не требует локального флага/Spreadsheet ID: валидная OAuth-сессия вкладки восстанавливает синхронизацию после перезагрузки.
- Google Identity Services инициализируется единожды; параллельные вызовы используют один init promise.
- Исправлено повторное перезаписывание намеренно пустого листа `TaskTemplates` при каждом обновлении.
- Обновлён Service Worker cache key до `work-time-shell-v7`, чтобы не использовать старый JS после публикации.
- Добавлены проверки восстановления сессии без localStorage-флагов, сохранения пустого списка шаблонов и проверки владельца таблицы при входе с общего устройства.
- При повторном аудите резервного календаря исправлен пропущенный государственный праздник 1 мая 2025 года.
