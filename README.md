# Work Time v3.0 — календарь списаний

Адаптивное PWA-приложение для учёта рабочего времени на GitHub Pages с онлайн-синхронизацией через Google Sheets.

## Изменения v3.0
- Журнал и календарь объединены: все списания добавляются/изменяются/удаляются прямо из выбранного дня календаря.
- Jira — булев флаг на записи. Сумма Jira рассчитывается по длительности целиком отмеченных записей.
- Шаблоны хранят только название задачи.
- В обзоре убран блок «По дням».
- Рабочий день фиксирован: 8 часов. Недостаток подсвечивается красным, переработка — жёлтым.
- Выходные и настроенные праздничные даты заблокированы для списаний и исключены из нормы.
- Интервалы отпуска, больничного и Day off настраиваются отдельно и автоматически учитываются как 8 часов за каждый рабочий день интервала.
- Старые данные мигрируют: числовой Jira объём преобразуется в флаг (если он был больше нуля); шаблоны сохраняют только название; старые статусы дней преобразуются в интервалы по одной дате.

## Развёртывание
1. Распакуйте архив и замените файлы в корне репозитория `phantasyq/worktime`.
2. Не удаляйте `config.js`: в нём находится OAuth Client ID приложения.
3. Сделайте commit в `main`; GitHub Pages обновится автоматически.
4. Откройте сайт с принудительным обновлением (Ctrl+F5) или в приватном окне. Service Worker обновлён до нового cache key.

## Работа с отсутствиями и праздниками
В «Настройки» добавляйте отпуск/больничный/Day off как интервалы. Приложение не позволит добавить период поверх существующих списаний: сначала нужно удалить или перенести эти записи. Праздничные дни вносятся вручную, поскольку официальный календарь зависит от страны и года.

## Проверка
Прогоните сценарии из `RELEASE_NOTES.md`. OAuth и вызовы Google Sheets API следует финально проверить в опубликованном экземпляре с реальным аккаунтом.

## Поведение дневной нормы
- Статус нормы рассчитывается по сумме обычных записей за день: меньше 8:00 — красный, ровно 8:00 — зелёный, больше 8:00 — жёлтый.
- Для интервалов отпуска/больничного/Day off на рабочих днях фиксируется зачёт 8:00 без отдельной записи и без Jira-флага.
- Суббота/воскресенье блокируются независимо от настройки рабочих дней; праздники задаются вручную в настройках.
